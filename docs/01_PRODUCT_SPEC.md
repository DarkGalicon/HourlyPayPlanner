# 01. Product Specification

## Цель

Сократить ручную работу при подготовке планового распределения и ежемесячных заявлений на почасовую оплату преподавателей.

## Пользователь

Один локальный пользователь. Многопользовательская работа, роли, серверная синхронизация и облачная БД в MVP не нужны.

## Входные данные MVP

- один или несколько XLSX-файлов «Индивидуальный план преподавателя», скачанных с `nagr.stgau.ru`;
- один преподаватель может иметь несколько XLSX: штатный преподаватель, внутренний совместитель, почасовик и т.п.;
- один XLSX может содержать очную нагрузку по осеннему/весеннему семестру и заочную нагрузку.

## Выходные данные

1. Нормализованная нагрузка преподавателя.
2. Расчетный лимит почасовой оплаты.
3. План распределения по дисциплинам/группам и месяцам.
4. Сгенерированные занятия по 2 часа с датой и временным слотом.
5. DOCX на выбранный месяц по существующему шаблону заявления.

## Не является целью MVP

- точный учет фактически проведенных занятий;
- интеграция с расписанием;
- автоматическая отправка документов;
- direct API/парсинг сайта `nagr.stgau.ru`;
- кадровый/бухгалтерский учет;
- расчет стоимости часа и суммы выплаты;
- многопользовательская работа;
- облачная синхронизация.

## Главный пользовательский сценарий

1. Создать/выбрать учебный год.
2. Импортировать XLSX преподавателя (возможно несколько файлов).
3. Проверить распознанные данные и предупреждения.
4. Задать/подтвердить эффективную ставку для расчета.
5. Выбрать, какие источники нагрузки учитывать как «фактические».
6. Получить расчет доступного объема почасовки.
7. Вручную выбрать допустимые аудиторные часы (Лек/Пр/Лаб).
8. Разложить выбранные часы по месяцам.
9. Задать доступность преподавателя и исключенные даты.
10. Сгенерировать даты/время на месяц.
11. При необходимости поправить расписание вручную или перегенерировать.
12. Сформировать DOCX.

## Нефункциональные требования

- кроссплатформенность Windows/macOS;
- локальная работа без сервера;
- понятные сообщения об ошибках импорта;
- отсутствие зависимости от Microsoft Office;
- сохранение данных между запусками;
- возможность резервного копирования SQLite-файла;
- корректная работа с русскими строками и именами файлов;
- внутренние расчеты часов — через `Decimal`.
