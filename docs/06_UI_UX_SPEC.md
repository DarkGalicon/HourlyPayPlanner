# 06. UI/UX Specification

PySide6. UI должен быть рабочим инструментом, а не демонстрационным dashboard.

## Главное окно

Верхняя навигация по этапам с краткой подсказкой и переходом к следующему шагу:

1. Импорт
2. Преподаватели
3. Расчет
4. План распределения
5. Расписание месяца
6. Документы
7. Настройки

«Настройки» доступны отдельно от шести последовательных шагов. Интерфейс
использует единую светлую тему, заметные основные действия и спокойное оформление
ошибок и подсказок. Цвет не должен быть единственным признаком состояния.

## 1. Импорт

Кнопка:

```text
Импортировать XLSX...
```

Поддержать multi-select файлов.

До записи в БД показать preview:

```text
Файл
Преподаватель
Тип занятости
Ставка в файле
Всего часов
Осень
Весна
Заочно
ИДПО
Предупреждений
```

Пользователь подтверждает импорт.

## 2. Карточка преподавателя

Показывать:

```text
ФИО
Учебный год
Эффективная ставка для расчета [editable]
```

Ниже — импортированные источники:

```text
[✓] учитывать в фактической нагрузке
Тип занятости
Ставка из файла
План часов
Имя файла
```

Не скрывать различие между `reported_rate` и `effective_rate`.

## 3. Расчет

Карточка:

```text
Эффективная ставка
Норма (ставка × 900)
Фактические часы выбранных источников
ИДПО
После вычета ИДПО
Превышение
Доступные Лек/Пр/Лаб
Максимум 300
К распределению
```

Предупреждения выводить отдельным блоком, кликабельным до исходной строки.

## 4. Выбор дисциплин

Фильтры:

```text
Семестр
Форма обучения
Дисциплина
Группа
Вид занятия
```

Таблица:

```text
Выбрать | Семестр | Дисциплина | Группа | Поток | Вид | Доступно | В почасовку
```

`В почасовку` редактируется вручную, шаг 2 часа.

Постоянный summary:

```text
Лимит: 180
Выбрано: 162
Осталось: 18
```

Если выбрано больше расчётного лимита, сохранение возможно только с отмеченной
галочкой явного разрешения. Превышать 300 часов и доступные часы строк нельзя.
В карточке преподавателя можно удалить импортированный источник после подтверждения,
если он не используется в сохранённом выборе нагрузки.

## 5. Помесячный план

Строки:

```text
Дисциплина | Группа | Вид | Выбрано | Сен | Окт | Ноя | Дек | Янв | Фев | Мар | Апр | Май | Остаток
```

Правила:

- cells spinbox step=2;
- неподходящие месяцы disabled;
- январь для 2 семестра включается флагом;
- строка valid только если остаток = 0.

Дополнительная команда:

```text
Распределить автоматически
```

Она может предложить равномерный черновик, но пользователь всегда может изменить его вручную.

## 6. Доступность преподавателя

Недельная сетка Пн–Пт × 7 слотов.

Пользователь отмечает разрешенные слоты.

Дополнительно:

- исключенная дата;
- разрешенные слоты для конкретной даты;
- глобальные праздничные даты.

## 7. Расписание месяца

Выбор месяца → `Сгенерировать`.

Таблица:

```text
Дата | Время | Группа | Дисциплина | Вид | Часы
```

Функции:

- Перегенерировать
- Изменить дату вручную
- Изменить время вручную
- Проверить конфликты
- Сбросить ручные изменения

При ручном выборе время/дата тоже должны проходить все validations.

## 8. Документы

Выбрать:

```text
Преподаватель
Месяц
Шаблон
Папка сохранения
```

Кнопка:

```text
Сформировать DOCX
```

После генерации:

```text
Открыть папку
Открыть документ
```

Не требовать наличия Microsoft Word.

## Ошибки

Не показывать stacktrace пользователю. Диалог должен содержать:

- что произошло;
- какой файл/строка, если применимо;
- что пользователь может сделать.
