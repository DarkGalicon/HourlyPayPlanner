# 08. Schedule Generator Specification

## Назначение

Преобразовать помесячные часы в строки занятий по 2 часа и назначить допустимые дату/время.

## Временные слоты

Зафиксированные исходные значения:

```text
1. 08:30-10:05
2. 10:15-11:50
3. 12:40-14:15
4. 14:25-16:00
5. 16:10-17:45
6. 17:55-19:30
7. 19:40-21:15
```

Хранить их как records с `sort_order`, `start_time`, `end_time`, `display_text`.

## Разрешенные дни

Только:

```text
Monday
Tuesday
Wednesday
Thursday
Friday
```

Суббота и воскресенье всегда исключены в текущей версии.

## Разгоночный период семестра

В начале каждого семестра сначала планируются лекции. Для каждого учебного года и
семестра пользователь задаёт единую первую допустимую дату практик/лабораторных.
Она действует для всех преподавателей, дисциплин и групп. Генератор и валидатор
запрещают практики/лабораторные до этой даты. Если дата не задана, такие занятия
генерировать нельзя; лекции не ограничены. Дата должна лежать в месяцах выбранного
семестра. Автоматический расчёт по «учебным неделям» не используется.

Лекции допустимы весь месяц, включая дни после первой даты практик/лабораторных.
Для них первые 14 календарных дней месяца имеют приоритет, но не являются
жёстким ограничением.

## Курс и форма обучения

Для первого курса допустим только слот, который заканчивается не позже 16:00.
Правило применяется и при ручном переносе. Для заочных строк предпочтительны слоты,
начинающиеся с 16:00; дневные слоты используются при нехватке вечерних. Поскольку
импорт не распознаёт очно-заочную форму отдельно, пользователь может включить
«Вечерний приоритет» у выбранной строки нагрузки. Он сохраняется в БД. При
совпадении с первым курсом предел 16:00 обязателен.

## Праздники

Иерархия:

1. базовый календарь `holidays` для РФ — как подсказка;
2. пользовательские глобальные исключения — приоритетнее;
3. пользователь может вернуть конкретную дату как рабочую, если внутренний распорядок отличается от общего календаря.

Не полагаться на онлайн API.

## Доступность преподавателя

Минимальная модель:

```text
weekday → allowed time slots
```

Дополнительно:

```text
excluded_dates
per_date_allowed_slots
```

Пример:

```text
Пн: все слоты
Вт: с 12:40 и позже
Ср: не ставить
Чт: все
Пт: первые 2 слота
```

## Конфликты

Для одного преподавателя запрещена повторная комбинация:

```text
date + time_slot
```

Промежутки между занятиями разрешены. Слоты не обязаны быть соседними.

## Генерация

Input:

```text
teacher
month/year
monthly allocations
availability
holiday/exclusion calendar
optional random seed
```

Алгоритм:

1. Каждую allocation разбить на `hours / 2` lesson units.
2. Построить все разрешенные `(date, slot)` месяца.
3. Удалить выходные, праздники и запрещенные правилами слоты.
4. Проверить capacity.
5. Сопоставить lesson units со свободными слотами с учётом жёстких ограничений
   и мягких приоритетов; сохранить seed для воспроизводимости.
6. Валидировать уникальность.
7. Сохранить `GenerationBatch` и `Lesson`.

## Capacity error

Если уроков больше, чем допустимых слотов:

```text
Не удалось распределить 6 часов.
Нужно занятий: 20.
Доступно свободных слотов: 17.
Измените доступность преподавателя или исключенные даты.
```

Не нарушать ограничения автоматически.

## Randomness

- random seed сохранять в `GenerationBatch` для воспроизводимости;
- кнопка «Перегенерировать» создает новый seed;
- ручные edits после генерации отмечаются `manual_override=True`;
- regenerate должен запросить подтверждение, если есть ручные edits.

## Ручной перенос и очистка месяца

Пользователь может перенести отдельное занятие на другую дату и временной слот
в пределах того же месяца. Группа, дисциплина, вид занятия и 2 часа остаются
связанными с исходным распределением. Перед сохранением применяются те же проверки,
что и при генерации: календарь, доступность, единая дата допуска Пр/Лаб и
уникальность пары `дата + слот` для преподавателя. Успешный перенос отмечается
`manual_override=True`; перегенерация запрашивает отдельное подтверждение.

Очистка расписания выбранного месяца требует подтверждения и удаляет занятия и
пакеты их генерации только для этого преподавателя и месяца. Помесячный план часов
не изменяется, поэтому расписание можно сгенерировать заново.

## Не вводить без требования пользователя

- лимит 3/4 занятия в день;
- обязательную последовательность временных слотов;
- привязку к реальному расписанию;
- запрет больших промежутков между занятиями.
