# Hourly Pay Planner

Локальное приложение для планирования и печати почасовой оплаты преподавателей по данным индивидуальных планов `nagr.stgau.ru`.

## Целевая среда

- Windows 10/11
- macOS (Intel/Apple Silicon — проверять при сборке)
- один локальный пользователь
- без сервера и обязательного интернет-соединения

## Основной поток

`XLSX → импорт → нормализованная нагрузка → расчет лимита → ручной выбор дисциплин → помесячное распределение → генерация занятий → DOCX`

## Текущее состояние интерфейса

Приложение открывает главное окно с навигацией по разделам. На каждом шаге есть
краткая подсказка и переход к следующему разделу; «Настройки»
доступны отдельно от основного потока. Светлая тема выделяет основные действия и
делает таблицы и сообщения единообразными. В разделе «Импорт» можно
выбрать несколько XLSX, посмотреть распознанные данные и предупреждения по каждому
файлу, затем подтвердить сохранение в локальную SQLite. Повторные файлы определяются
по SHA-256 и не сохраняются, кроме переимпорта источника, прочитанного старой версией
парсера. После такого переимпорта старый источник можно удалить в разделе
«Преподаватели» (если его строки не используются в сохранённом выборе нагрузки).
В разборе нагрузки часы из графы «Итого», не расшифрованные по видам работ, учитываются
в общем плане с предупреждением, но недоступны для почасовки; консультации к экзамену,
указанные вне «Итого», не прибавляются к плану повторно. В разделе «Преподаватели» можно
отредактировать ФИО и данные для шапки заявления (кафедру, степень,
звание, должность, дату рождения, адрес, паспорт, СНИЛС и ИНН). Сохранённые
данные подставляются в DOCX; незаполненные поля шаблона остаются пустыми.
Дата рождения и дата выдачи паспорта вводятся в формате `ДД.ММ.ГГГГ`.
Вкладка «Преподаватели» прокручивается целиком: все поля и источники доступны
даже на небольшом экране ноутбука.
Исправление ФИО не мешает повторному импорту планов с исходным именем из XLSX.
Персональные данные хранятся в локальной базе приложения; резервные копии базы
следует защищать так же, как сами документы.
Здесь же можно подтвердить эффективную ставку, выбрать источники фактической
нагрузки или удалить импортированный источник из базы после подтверждения.
Исходный XLSX при этом не удаляется; источник со
связанным выбором нагрузки удалить нельзя. Ставки из файлов
показаны отдельно и не суммируются автоматически. В разделе «Расчет» отображаются
норма, часы включенных источников, ИДПО, превышение и лимит почасовки, а также
предупреждения импорта с привязкой к файлу, листу и строке. До подтверждения ставки
и выбора источников расчет не выполняется. В разделе «План распределения» можно
отфильтровать допустимые аудиторные строки, вручную выбрать кратные двум часы и
сохранить их в пределах лимита. Галочка «Разрешить превышение расчётного лимита»
позволяет сохранить больше расчётного остатка, но не более 300 часов на
преподавателя и не больше доступных часов по строкам. Разрешение запоминается
отдельно для преподавателя и учебного года. Выбор хранится отдельно по учебным годам. На вкладке
«По месяцам» выбранные часы распределяются вручную между месяцами соответствующего
семестра; январь включается отдельно, а для заочных строк без семестра его нужно
указать явно. План сохраняется только при совпадении суммы месяцев с выбранными
часами. Помесячный план учебного года можно очистить с подтверждением, если по нему
ещё не созданы занятия. В разделе «Расписание месяца» на вкладке «Доступность» можно
задать разрешённые слоты Пн–Пт, исключённые даты и слоты для отдельных дат.
В «Настройках» можно просмотреть базовые праздники РФ и задать глобальные нерабочие
или разрешённые рабочие даты. На вкладке «Занятия» можно сгенерировать и проверить
расписание выбранного месяца по сохранённому плану, доступности и календарю.
Перегенерация требует подтверждения и отдельно предупреждает о ручных изменениях.
Генератор предпочитает ставить лекции в первые 14 дней месяца, но может ставить их
позже. Занятия первого курса заканчиваются не позже 16:00. Заочные строки
предпочитают вечерние слоты; для очно-заочных строк включите «Вечерний приоритет»
в разделе «План распределения → Выбор нагрузки» — он сохраняется с выбором часов.
Выбранное занятие можно вручную перенести на другую допустимую дату и временной слот
в том же месяце; такая правка отмечается в таблице. Кнопка «Очистить месяц» после
подтверждения удаляет занятия месяца, но сохраняет помесячное распределение часов.
В разделе «Документы» можно выбрать преподавателя и месяц с сохранённым расписанием,
DOCX-шаблон и папку назначения. Перед экспортом проверяются допустимость занятий и
совпадение их количества с помесячным планом. Степень, звание, должность и дату
заявления можно включить отдельно (дата включена по умолчанию); формулировки видов занятий редактируются на экране.
Экспорт не заменяет существующий файл — для повторного вывода выберите другую папку
или переместите прежний документ.
На соседней вкладке «Распределение XLSX» формируется план на весь учебный год по
сохранённым помесячным часам. Бланк создан из листа «почасовка» добавленного шаблона
`.xls`; старый формат преобразован в `.xlsx` заранее, поэтому установленный Excel или
LibreOffice для работы приложения не нужен. Для каждой строки пользователь явно
выбирает «бюджет» или «коммерция»; лабораторные выводятся отдельной секцией.
Шифры специальности и дисциплины остаются пустыми, поскольку импортированный план
не содержит этих полей. Файл с тем же именем не перезаписывается.

Во вкладке «Настройки → Начало семестра» задайте единую первую допустимую дату
практик/лабораторных для каждого семестра учебного года. До неё генератор ставит
только лекции. Без явно заданной даты практики/лабораторные не генерируются;
длительность разгона по неделям программа не угадывает.

## Быстрый старт в PyCharm

1. Установить Python 3.12.
2. Установить `uv`.
3. Открыть корень проекта в PyCharm.
4. В терминале проекта выполнить:

```bash
uv sync --all-groups
```

5. В PyCharm выбрать интерпретатор `.venv`.
6. Запуск приложения:

```bash
uv run python -m hourly_pay
```

7. Запуск тестов:

```bash
uv run pytest
```

8. Проверка стиля:

```bash
uv run ruff check .
```

## Сборка приложения

Конфигурация PyInstaller находится в `HourlyPayPlanner.spec`. Однопапочная сборка
выполняется на целевой ОС командой `uv run --no-sync python -m PyInstaller --noconfirm
HourlyPayPlanner.spec`. На macOS Apple Silicon собранный `.app` прошёл проверку
запуска и миграций на временной БД. Windows и macOS Intel требуют проверки на
соответствующих машинах. Подробные шаги — в `docs/12_BUILDS.md`.

## Приватные тестовые файлы

Реальные XLSX/DOCX могут содержать персональные данные. Не коммитить их в Git.

Рекомендуемая локальная папка:

```text
tests/fixtures_private/
```

Она должна быть в `.gitignore`. Для публичных автотестов позднее создать синтетические обезличенные fixtures.
